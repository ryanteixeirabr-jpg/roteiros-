## Como registrar uma pauta

| Campo | Descrição |
|---|---|
| Tema | Assunto em uma linha |
| Gancho | Pergunta/fato que chama atenção |
| Área | Trabalho / Eleitoral / Internet / Direitos / Curiosidade jurídica / Atualidade |
| Público | Empregado / Empresário / Ambos |
| Formato | Pergunta e resposta (Ryan + Vitor) / Solo / YouTube |
| Status | Ideia / Aprovada / Roteirizada / Gravada / Postada |
| Observações | Ressalvas (🟡) para possíveis comentários, base jurídica, data de relevância |
